# Electricity Monitor Release Package

This package is generated by GitHub Actions for Alibaba Cloud Linux 3 amd64 deployment.

## Contents

- `images/`:
  - `electricity-monitor-__RELEASE_TAG__-linux-amd64.tar.gz`
  - `redis-8-alpine-linux-amd64.tar.gz`
- `compose.yaml`
- `deploy.sh`
- `smoke.sh`
- `.env.example`
- `release-manifest.json`

## Deployment

1. Extract `release-__RELEASE_TAG__.tar.gz`.
2. Copy `.env.example` to `.env`.
3. Create the secret files referenced by `.env` under `./secrets/`.
4. Run:

```bash
chmod +x deploy.sh
./deploy.sh
./smoke.sh
```

Deployment writes `deploy-result.json` beside the release files so the server keeps a basic record of the deployed tag / SHA / image digest.

## Runtime contract

- Runtime style: `docker compose`
- Restart policy: `unless-stopped`
- Health check: `GET /api/health`
- Stable containers:
  - `electricity-app`
  - `electricity-redis`

## Rollback behavior

If deployment health checks fail, `deploy.sh` will:

1. stop and remove the new containers
2. rename backup containers back to the stable names
3. restart the previous app and Redis containers

Old images are additionally tagged with `rollback-<timestamp>` for inspection.
